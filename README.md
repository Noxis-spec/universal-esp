# Universal Mobile ESP

A lightweight, high-performance ESP script optimized specifically for Roblox Mobile executors. It renders player visibility through solid structures and walls while utilizing the Rayfield UI Library for a streamlined configuration interface.

---

## Features

- 2D Box ESP
- Health Bar
- Name and Distance display
- Team Check filtering
- Distance Culling (up to 500 studs maximum rendering)
- Rayfield UI (clean, interactive menu with individual toggles)

---

## How to Use

1. Copy the source code from the main.lua file.
2. Paste the script into your mobile executor of choice.
3. Press Execute to load the UI panel.
4. Use the Rayfield menu toggles to seamlessly configure individual functions.

---

## Quick load

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Noxis-spec/universal-esp/main/main.lua"))()
```
